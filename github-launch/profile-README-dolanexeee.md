# URUK — أوروك

Open-source software suite, built clean-room from public documentation and observed behavior.
First app: **Uruk Cut** — a short-form video editor for web and desktop.

## Uruk Cut

- **Web:** https://uruk-cut.vercel.app
- **Desktop:** Tauri app with native FFmpeg export (Linux installers in Releases; Windows & macOS via CI)
- **Parity:** 98.3% of a publicly defined 30-item core-use checklist — see `PARITY.md` in the repo, scored honestly, never rounded up
- **Captions:** on-device Whisper speech-to-text, Arabic + English, burned into exports — your media never leaves your device
- **License:** Apache-2.0

Clean-room means: no proprietary code, assets, or branding from any commercial editor was read, decompiled, or copied. Concepts like timelines, trimming, and export are industry common practice; every line here is original.
